Make it yours

  1. After installation, restart the tile if it does not restart automatically.
  2. Open Settings → Wi-Fi setup on the tile. Join its setup Wi-Fi from your phone and open http://192.168.4.1.
  3. Choose your home Wi-Fi and enter your OpenAI API key on the tile’s local setup page.
  4. Open GPT Live on the tile to get started. Future firmware updates arrive over Wi-Fi.

This installer never asks for your Wi-Fi password or API key. Enter those only on your tile’s local setup page.

Need a hand?

My tile does not appear in the USB list

Try a USB data cable instead of a charging-only cable. Close serial monitors and other apps using the tile, then reconnect it. If needed, hold the tile’s BOOT button while pressing and releasing RESET, release BOOT, and try again.

Can I use my phone?

Use a desktop computer for the first USB installation. Once installed, you can use your phone for Wi-Fi setup and the tile can update itself.

What about Stable?

Preview is our active testing channel. Stable is not available yet. This installer sets the tile to receive Preview updates.
